# Pack `fr-tech-founders-2026.1`

Population : Actifs de 25 à 45 ans des métiers du numérique (cadres, professions intermédiaires, indépendants, dirigeants de petites structures, personnes en transition) qui envisagent, à un degré quelconque, de créer une entreprise ; France métropolitaine. Âges de référence au 1er janvier 2026.

Ce pack est construit ainsi :
- **socle `fr`**, hérité par le champ `extends` : toute table absente de ce dossier est reprise telle quelle (impôts et prestations, coûts, logement, abonnements grand public, prénoms, unités urbaines, activité des conjoints et parents…) ;
- **surcharges de population** ;
- **module activé : [`entrepreneuriat-tech`](../../modules/_archive/entrepreneuriat-tech/module.yaml)** (archivé : lisible pour ce pack et ses études, hors de la bibliothèque proposée). Il apporte statut, métier, revenu, stade du projet, préférence d'équipe, freins, réseaux, outils pro et heures disponibles. Ses sources et hypothèses sont dans le module ; le format est décrit dans [docs/modules.md](../../docs/modules.md).

Les personas ont des ids `fr-tech-founders-2026.1-s<graine>-<rang>` et se filtrent en base par `pack_version = 'fr-tech-founders-2026.1'`. Leurs attributs de module sont dans `extra.modules["entrepreneuriat-tech"]`.
