# Pack France `fr-2026.1`

Population : Adultes de 18 à 79 ans résidant en France métropolitaine (ménages ordinaires). Âges de référence au 1er janvier 2026.

Chaque fichier JSON contient `sources`, `referenceYear`, `notes` (méthode, approximations) et `data`. Les hypothèses de modélisation portent `"assumption": true` et une `justification`. Le chargeur (`src/personas/pack.ts`) refuse une table sourcée sans source ni année, et une hypothèse sans justification. Toute modification des données doit incrémenter `version` dans `pack.json` : les personas gardent la version qui a servi à les tirer.
